I enjoy building practical software applications, exploring artificial intelligence, and turning ideas into digital products. My goal is to combine **full-stack development, AI engineering, and intelligent automation** to build useful solutions for real-world problems.

- 🎓 **Education:** BS Computer Science — FUUAST, Islamabad.
- 💻 **Development:** Building web applications using Python, JavaScript, React, Next.js, and the MERN stack.
- 🤖 **AI & Automation:** Exploring AI agents, LLM integrations, chatbots, RAG, and workflow automation.
- 🐍 **Python:** Learning and building projects from fundamentals to advanced applications.
- 🚀 **Entrepreneurship:** Co-founder/CEO of SYFA Digital, focused on digital solutions.
- 🛍️ **Product Development:** Exploring e-commerce, SaaS applications, and AI-powered tools.
- 🌱 **Current mission:** Improve my engineering skills by building, testing, documenting, and deploying real-world projects.
- 🤝 **Let's connect:** I'm interested in collaborating on software development, AI, and automation projects.
